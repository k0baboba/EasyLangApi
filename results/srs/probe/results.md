# Модель планировщика на данных Duolingo

Данные: B. Settles, B. Meeder. *A Trainable Spaced Repetition Model for Language Learning*, ACL 2016; файл `settles.acl16.learning_traces.13m.csv.gz` (Harvard Dataverse), лицензия CC BY-NC 4.0. Ниже только агрегаты, посчитанные скриптом `srs/srs_sim/duolingo.py`; сами данные не публикуются.

- Строк: 200,000 (пропущено некорректных: 0), пользователей: 5,130, слов: 7,666
- Период: 2013-02-28 18:28 UTC — 2013-02-28 23:04 UTC
- Обучение: первые 80% строк по времени (160,000), проверка: строки с 2013-02-28 22:28 UTC (40,000)
- В проверке у 14,192 строк есть прошлая сессия той же пары в данных (для остальных признак «последний раз ошибка» = 0)

| **Наш планировщик** (HLR, признаки AdaptiveScheduler) | 0.1205 | 0.5378 | 0.0932 | 0.983 | 0.900 |

- MAE — средняя |p̂ − доля верных в сессии| по строкам проверки.
- AUC — по отдельным ответам: каждая строка даёт session_correct верных и session_seen − session_correct неверных ответов с одной оценкой p̂. 0.5 — не лучше случайного.
- ECE — средняя по ответам |p̂ − доля верных| в 10 корзинах по p̂.

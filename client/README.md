# EasyLang — клиент для Windows

Маленькое приложение в трее: по хоткею снимает область экрана, отправляет её на сервер
(`POST /recognize`) и показывает распознанный текст. Клик по слову (Shift+клик — добавить
к фразе) и «Разобрать» — `GET /lines/{id}/explain`. Вся логика — распознавание, контекст,
словарь, повторение — на сервере; клиент только снимает экран и показывает ответы.

> **Не проверен на Windows.** Собран в облачной среде на Linux (`EnableWindowsTargeting`),
> но ни разу не запускался. См. [STATUS.md](../STATUS.md).

## Запуск

1. Запустите сервер (`dotnet run` в корне репозитория или `docker compose up`).
2. Проверьте адрес сервера в `settings.json` (по умолчанию `http://localhost:5057`;
   для Docker — `http://localhost:8080`).
3. ```bash
   dotnet run --project client/EasyLangClient
   ```
4. Войдите или зарегистрируйтесь, затем в игре нажмите хоткей (по умолчанию `Ctrl+Shift+E`)
   и выделите мышью окно с текстом. `Esc` — отмена.

## Как это устроено

| Файл | Что делает |
|---|---|
| `Program.cs` | Читает `settings.json`, создаёт `HttpClient`, запускает приложение в трее |
| `TrayApplicationContext.cs` | Иконка в трее, хоткей, сценарий «снимок → область → распознать → показать» |
| `HotkeyWindow.cs`, `Native.cs` | Глобальный хоткей через `RegisterHotKey`, заголовок активного окна |
| `ScreenCapture.cs`, `RegionSelectForm.cs` | Стоп-кадр всех мониторов и выбор прямоугольника поверх него |
| `ApiClient.cs` | HTTP API сервера: вход, обновление токена при 401, распознавание, разбор |
| `ResultForm.cs` | Окно с текстом, кликабельные слова, результат разбора |
| `LoginForm.cs` | Вход и регистрация |

Заголовок активного окна отправляется как `title` — сервер добавляет его в контекст разбора.
Скриншоты одного окна дописываются в один эпизод (`episodeId`), поэтому предыдущие реплики
диалога тоже попадают в контекст.

## Настройки (`settings.json`)

| Ключ | Смысл |
|---|---|
| `serverUrl` | Адрес сервера |
| `email` | Последний email для входа (запоминается) |
| `hotkey` | Например `Ctrl+Shift+E`, `Alt+F9` |
| `useWindowTitleAsTitle` | Отправлять заголовок окна как название произведения |

## Известные ограничения

- Токены хранятся только в памяти: после перезапуска клиента нужно войти снова.
- Полноэкранные игры в эксклюзивном режиме могут не отдавать картинку через `CopyFromScreen`
  и перехватывать хоткей — используйте оконный режим без рамки.
- Мониторы с разным масштабом (DPI) не проверялись.

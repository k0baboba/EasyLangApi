# Тренажёр EasyLangApi

20 коротких шагов по 10 задачам из [`docs/guide.md`](../docs/guide.md), раздел 5.
Каждый шаг занимает 10–20 минут, первый шаг задачи обычно меньше 10.
Темы идут в порядке, в котором их стоит подтягивать (см. `CLAUDE.md`):

| Шаги | Задача | Тема |
|---|---|---|
| 01–02 | 1. Параллельные запросы к словарю | async/await |
| 03–04 | 2. Повторные попытки | HttpClient |
| 05–06 | 3. Постраничный словарь | LINQ |
| 07–08 | 4. Фильтр и сортировка словаря | LINQ, лямбды, делегаты |
| 09–10 | 5. Гонка при создании элемента | исключения |
| 11–12 | 6. Статистика повторений | SQL, LINQ GroupBy |
| 13–14 | 7. Двойной ответ | SQL, EF Core |
| 15 | 8. Индекс для квоты | индексы, миграции |
| 16–17 | 9. Запасной разборщик | DI, декоратор |
| 18–20 | 10. Субтитры WebVTT | интерфейсы, DI, регулярные выражения |

## Как работать

Windows (PowerShell 5.1 или 7), из корня репозитория:

```powershell
.\exercises\next.ps1
```

Скрипт прогоняет тесты тренажёра, находит первый шаг с красными тестами и
показывает условие, что почитать и какие тесты красные. Дальше:

```powershell
.\exercises\next.ps1 -Hint 1     # подсказка 1, потом 2 и 3 — готового решения в них нет
.\exercises\next.ps1 -List       # все шаги и их состояние
.\exercises\next.ps1 -Step 7     # прочитать шаг 7, не прогоняя тесты
```

Если PowerShell не даёт запустить скрипт, разрешите локальные скрипты для текущего окна:

```powershell
Set-ExecutionPolicy -Scope Process RemoteSigned
```

Linux и macOS: `pwsh exercises/next.ps1` или просто
`dotnet test exercises/Exercises.Tests --filter "FullyQualifiedName~Step01"`.

## Правила

- Тесты уже написаны. Код приложения пишете вы, тесты не трогайте.
- Один шаг — один коммит. Сессия заканчивается коммитом, даже если шаг не закончен.
- После каждого шага основные тесты должны остаться зелёными:
  `dotnet test tests/EasyLangApi.Tests`.
- Если шаг не идёт, читайте подсказки по одной. Если и после третьей
  непонятно — разрежьте шаг пополам и напишите, на чём застряли.
- Любую написанную строку вы должны уметь объяснить и переписать сами.

## Как устроено

- `steps/NN-*.md` — условия шагов: условие, что почитать, три подсказки.
- `Exercises.Tests/StepNN/` — тесты шага в пространстве имён `Exercises.StepNN`.
  Шаг закрыт, когда все его тесты зелёные.
- `Exercises.Tests/Infrastructure/` — подставной HTTP со счётчиком
  одновременных запросов и `SaveChangesBarrier`, который делает гонки
  воспроизводимыми. Общая часть (`ApiFactory` и др.) подключена ссылками из
  `tests/EasyLangApi.Tests/Infrastructure`.
- Папка исключена из сборки приложения в `EasyLangApi.csproj` и из Docker-образа.
- Решения лежат только в ветке `exercises-solutions`. CI
  (`.github/workflows/exercises.yml`) проверяет, что на ветке `exercises` каждый
  шаг красный, а на `exercises-solutions` все зелёные, и запускает `next.ps1`
  на `windows-latest` в Windows PowerShell 5.1.

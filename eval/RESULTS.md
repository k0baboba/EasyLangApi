# Результаты: помогает ли контекст сцены разбирать фразы

**Гипотеза.** Языковая модель, которой передан контекст сцены, объясняет сленг и многозначные слова
верно чаще, чем словарь и та же модель без контекста. **На этом наборе гипотеза подтвердилась.**
Как устроен набор, сказано в ограничениях: на обычный текст результат переносить нельзя.

**Прогон.** 150 фраз, три варианта:
- словарь — `api.dictionaryapi.dev`, как `DictionaryExplainer`;
- LLM без контекста;
- LLM с контекстом: название, говорящий, две реплики до и две после.

Модель разбора — `qwen2.5:7b` в Ollama на CPU раннера GitHub Actions (workflow `eval-live`, run 41858643540).
Судья — `llama3.1:8b`, фразу он не видит. Файлы прогона лежат в `results/`, сырые ответы — в ветке `results`,
папка `results/eval/full-judge-v2/`.

## Главные числа

Главное число — **слепая оценка** 120 случайных ответов (seed 2026). Проверяющий не видел ни варианта,
ни вердикта судьи. Рядом — вердикт LLM-судьи на всех фразах. В скобках 95 % интервал Уилсона.

| Вариант | Слепая оценка, верно | Судья, верно |
|---|---:|---:|
| Словарь | 13 из 40 = 32 % [20–48] | 63 из 146 = 43 % [35–51] |
| LLM без контекста | 16 из 37 = 43 % [29–59] | 67 из 150 = 45 % [37–53] |
| **LLM с контекстом** | **38 из 43 = 88 % [76–95]** | **133 из 150 = 89 % [83–93]** |

- **Парное сравнение по судье** (одни и те же фразы, точный тест Макнемара):
  - против LLM без контекста: только с контекстом верно 68 фраз, только без контекста — 2 (p ≈ 4·10⁻¹⁸);
  - против словаря: 72 фразы против 4 (p ≈ 4·10⁻¹⁷).
- **Контрольные фразы** — 25 штук, в них верен буквальный смысл. LLM без контекста в 9 из 25 выбрала
  сленговое прочтение, LLM с контекстом — в 1, словарь — в 1 из 24. По судье на контрольных фразах верно:
  словарь 96 %, без контекста 60 %, с контекстом 92 %.
- **Согласие судьи со слепым проверяющим:** «верно / неверно» совпало в 107 из 120 случаев (89 %),
  каппа Коэна 0,78. Судья **завышает**: в 11 случаях он поставил «верно», а проверяющий «неверно»,
  обратных случаев 2. Сильнее всего завышение у LLM без контекста (59 % против 43 % на той же выборке)
  и у словаря (40 % против 32 %). Подробности — `results/blind/agreement.md`.

## Ограничения

- **Фразы и правильные ответы сочинил автор эксперимента.** Носители их не проверяли.
- **Набор подобран так, чтобы контекст был важен.** Реплики однозначно указывают смысл, поэтому разница
  между вариантами не описывает обычный текст, где контекст беднее, а большинство слов однозначны.
- **Судья сам языковая модель** и завышает оценки, см. выше. Слепой проверяющий — тоже модель
  (отдельный субагент Claude), а не человек. Проверки людьми не было.
- **Модель разбора одна** (`qwen2.5:7b`, температура 0.2, один прогон). Другие модели и повторные прогоны
  не проверялись.
- **В 8 из 150 ответов `llm_context`** в переводе или смысле есть иероглифы: модель сбивается на китайский.
  В полном ответе модели, с примером, таких ответов 11.
- **Словарь.** 4 из 150 запросов закончились ошибкой 502, они не оценены. У словаря оценивается первое
  значение — то, что приложение показывает первым.
- **Слепая выборка невелика:** 37–43 ответа на вариант. Варианты в ней не парные, поэтому интервалы широкие.

Файлы: `results/results.md` и `results/run.json` — сводка прогона и его настройки.
`results/blind/` — выгрузка с оценками проверяющего (`blind.csv`, `grader_answers.csv`), ключ (`blind_key.json`)

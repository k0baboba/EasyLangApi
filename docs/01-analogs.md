> **Как читать пометки.**
> - **[факт]** — утверждение есть в источнике, ссылка рядом. Первоисточник

## 1.1. Критерии сравнения

Критерии выбраны под задачу проекта (см. `02-problem-statement.md`):

| № | Критерий | Зачем |
|---|---|---|
| К1 | Источник текста: перехват из процесса (hook), OCR с экрана, субтитры, камера | Насколько система универсальна для игр |
| К2 | Где выполняется OCR: на устройстве или в облаке | Связано с разделом 5 |
| К3 | Учёт контекста при объяснении (название произведения, соседние реплики) | Ключевое отличие EasyLangApi |
| К4 | Личный словарь и интервальное повторение (SRS) | Обучение, а не только перевод |
| К5 | Связь с Anki | Стандарт де-факто для карточек |
| К6 | Модель распространения и лицензия | Открытость, стоимость |

## 1.2. Аналоги

### Playto

Десктопное приложение для Windows: изучение языков во время игры в ПК-игры.

- [факт] ⚠ Распознаёт текст на экране локальным OCR и показывает значение
  поверх игры в оверлее; работает поверх любой игры без модов.
  Источник: [страница в Steam](https://store.steampowered.com/app/4603950/Playto/),
  [сайт разработчика](https://playto-site.pages.dev/),
  [описание оверлея](https://playto-site.pages.dev/docs/features/overlay.html).
- [факт] ⚠ Есть личный словарь (Word Book), SRS-повторение, режимы квизов,
  озвучка, экспорт в Anki, пометка слов по уровню CEFR/JLPT.
  Источник: [Steam](https://store.steampowered.com/app/4603950/Playto/),
  [FAQ](https://playto-site.pages.dev/docs/faq/).
- [факт] ⚠ Ранний доступ (Early Access) в Steam; есть бесплатная версия
  Playto Lite. Источник: [блог разработчика](https://playto-site.pages.dev/blog/lite-available/),
  [itch.io](https://playto-app.itch.io/playto).
- [факт] ⚠ Используется «локальный OCR и ИИ» — так сформулировано в описании.
  Где именно работает языковая модель (на устройстве или в облаке), из
  поисковой выдачи установить не удалось. **Требует проверки.**
- [предположение] Playto — ближайший аналог по сценарию (игра → оверлей →
  словарь → SRS). Отличие EasyLangApi нужно формулировать через К3:
  передача контекста сцены в промпт и разделение «наблюдения» и «элемента
  знания» в модели данных.

### Game2Text

Открытое приложение для изучения языков по играм, в основном японского.

- [факт] Платформы: Windows 10, macOS (Mojave, Catalina). Стек: Python, Eel,
  SudachiPy (морфологический анализ японского), FFmpeg.
  Источник: [README на GitHub](https://github.com/mathewthe2/Game2Text).
- [факт] OCR: локальный Tesseract 4.1.1 / Tesseract Legacy или облачный
  OCR Space. Есть перехват текста из визуальных новелл через Textractor и
  режим буфера обмена. Источник: [README](https://github.com/mathewthe2/Game2Text).
- [факт] Словарь — через браузерные расширения Yomichan / Rikaichan; карточки
  Anki со скриншотом и аудио через AnkiConnect.
  Источник: [README](https://github.com/mathewthe2/Game2Text).
- [факт] Лицензия Apache-2.0; опубликованных релизов в разделе Releases нет.
  Источник: [репозиторий](https://github.com/mathewthe2/Game2Text).
- [сторонний] Последний push в репозиторий — сентябрь 2023.
  Источник: [ecosyste.ms](https://awesome.ecosyste.ms/projects/github.com%2Fmathewthe2%2Fgame2text).
- [факт] Есть родственные проекты: Game2Text-Lightning
  ([GitHub](https://github.com/mathewthe2/Game2Text-Lightning)) и
  GameSentenceMiner
  ([ecosyste.ms](https://awesome.ecosyste.ms/projects/github.com%2Fbpwhelan%2Fgamesentenceminer)).
- [предположение] Собственного SRS нет: повторение отдано Anki. Контекст
  произведения в объяснение не передаётся, потому что объяснение даёт
  обычный словарь.

### LunaTranslator

Открытый переводчик визуальных новелл (galgame).

- [факт] Основной способ получения текста — перехват (HOOK) из процесса игры,
  в том числе для эмуляторов NS/PSP/PSV/PS2; для части игр — встроенный
  перевод прямо в игре. Источник: [README на GitHub](https://github.com/HIllya51/LunaTranslator).
- [факт] Встроенная модель OCR и поддержка многих других онлайн- и
  офлайн-движков OCR. Источник: [README](https://github.com/HIllya51/LunaTranslator).
- [факт] Поддерживает «почти все движки перевода», включая перевод большими
  языковыми моделями и офлайн-перевод. Источник: [README](https://github.com/HIllya51/LunaTranslator).
- [факт] Для изучения языка: сегментация и фуригана для японского,
  AnkiConnect, плагин Yomitan; много движков синтеза речи.
  Источник: [README](https://github.com/HIllya51/LunaTranslator).
- [факт] Лицензия GPLv3. Источник: [README](https://github.com/HIllya51/LunaTranslator).
- [сторонний] Порядка 11 тыс. звёзд на GitHub.
  Источник: [ecosyste.ms](https://awesome.ecosyste.ms/projects/github.com%2Fhillya51%2Flunatranslator).
- [предположение] Это прежде всего переводчик, обучение в нём —
  вспомогательная функция. Передаёт ли он соседние реплики в промпт языковой
  модели, по README установить нельзя. Проверить по документации на
  lunatranslator.org.

### Translumo

Открытый экранный переводчик для Windows.

- [факт] Распознаёт и переводит текст в выбранной области экрана в реальном
  времени: субтитры, игры. Источник: [README на GitHub](https://github.com/Danily07/Translumo).
- [факт] Движки OCR: Windows OCR (рекомендуемый: быстрый, достаточен для
  большинства текстов) и EasyOCR (лучше на необычных шрифтах и сложном фоне,
  но медленнее и требует GPU Nvidia). Есть комбинированный режим: несколько
  движков работают одновременно, а модель машинного обучения выбирает лучший
  результат. Источник: [README](https://github.com/Danily07/Translumo).
- [сторонний] В более ранних версиях README упоминался также Tesseract 5.2.
  В текущем README, открытом при сборе, его нет. **Проверить по истории
  репозитория.**
- [факт] Требования: для Windows OCR — Windows 10 2004+ или 11, GPU с
  DirectX 11, 2 ГБ ОЗУ; для EasyOCR — GPU Nvidia с CUDA 11.8, 8 ГБ ОЗУ,
  от 5 ГБ на диске. Источник: [README](https://github.com/Danily07/Translumo).
- [факт] Переводчики: Google Translate, DeepL, Yandex. Стек: C#, .NET 8.
  Лицензия Apache-2.0. Источник: [README](https://github.com/Danily07/Translumo).
- [факт] Функций словаря и обучения в Translumo нет; README отсылает к
  отдельному коммерческому продукту Lookupper («экранный словарь для изучения
  языка»). Источник: [README](https://github.com/Danily07/Translumo).
- [факт] Есть форк Translumo-LLM с переводом через языковые модели, включая
  локальный Ollama. Источник: [GitHub](https://github.com/Chaobs/Translumo-LLM/releases).
- [предположение] Translumo — ближайший аналог по стеку (C#/.NET, Windows) и
  хороший пример компромиссов OCR на клиенте: см. раздел 5.

### Migaku

Коммерческое расширение браузера и мобильные приложения для изучения языков
по видео и текстам.

- [факт] ⚠ Работает на YouTube, Netflix, Disney+, Rakuten Viki, Animelon.
  Источник: [Chrome Web Store](https://chromewebstore.google.com/detail/migaku-legacy/acpchjgielgmkgkplljakcibfbjjppbk).
  Актуальная версия расширения опубликована отдельно:
  [Migaku: Learn Languages](https://chromewebstore.google.com/detail/migaku-learn-languages/lkhiljgmbeecmljiogckofcalncmfnfo).
- [сторонний] ⚠ Поиск слов в субтитрах, создание карточек с контекстом в один
  клик, собственное SRS, оценка понятности контента, синхронизация с
  мобильными приложениями. Источники:
  [Tofugu](https://www.tofugu.com/japanese-learning-resources-database/migaku/),
  [Coto Academy](https://cotoacademy.com/how-to-use-migaku-browser-extension/).
- [сторонний] ⚠ Объяснение употребления слова в конкретном предложении с
  помощью языковой модели. Источник: [aichief.com](https://aichief.com/ai-education-tools/migaku/).
  Официального подтверждения не найдено.
- [факт] ⚠ Платная подписка с пробным периодом; цены в источниках расходятся.
  Официальная страница: [migaku.com/pricing](https://migaku.com/pricing),
  [FAQ по ценам](https://migaku.com/faq/pricing).
- [предположение] По К3 Migaku ближе всех к идее EasyLangApi: объясняет
  слово в предложении. Но источник текста — веб-видео и тексты, не игры.

### Language Reactor

Расширение Chrome для просмотра видео с двойными субтитрами.

- [факт] ⚠ Двойные субтитры, всплывающий словарь, точное управление
  воспроизведением; Netflix, YouTube, Disney+. Источник:
  [Chrome Web Store](https://chromewebstore.google.com/detail/language-reactor/hoombieeljmmljlkjmnheibnpciblicm).
- [факт] ⚠ В Pro-версии: ИИ-словарь Lexa; сохранённые слова подсвечиваются
  и экспортируются в Anki. Источник: [страница Pro](https://languagereactor.com/pro-mode).
- [сторонний] Встроенное повторение PhrasePump, экспорт CSV/TSV, цены
  около $5 в месяц (данные блога конкурента). Источники:
  [форум](https://forum.languagelearningwithnetflix.com/t/pro-features/13025/2),
  [Trancy](https://www.trancy.org/blog/trancy-vs-language-reactor-which-is-better-in-2026-3179d225200580118e5adf26153345a1).
- [сторонний] Есть отзывы о том, что расширение давно не обновлялось; другие
  источники это опровергают. Источник: [Chrome Web Store, отзывы](https://chromewebstore.google.com/detail/language-reactor/hoombieeljmmljlkjmnheibnpciblicm).
- [предположение] Текст берётся из готовых дорожек субтитров, OCR не нужен.
  Это ближе всего к V1 прототипа (вход — файл `.srt`), но не к сценарию с играми.

### Anki

Открытая программа карточек с интервальным повторением; эталон для
подсистемы повторения.

- [факт] ⚠ Начиная с Anki 23.10 доступны два алгоритма: основанный на
  SuperMemo 2 и FSRS. Источник: [официальный FAQ](https://faqs.ankiweb.net/what-spaced-repetition-algorithm),
  [то же в документации](https://docs.ankiweb.net/faqs/what-spaced-repetition-algorithm).
- [факт] ⚠ По данным FAQ, с FSRS для того же уровня запоминания требуется
  меньше повторений, и алгоритм лучше планирует карточки, повторённые с
  опозданием. Источник: там же.
- [факт] FSRS — вариант модели DSR (Difficulty, Stability, Retrievability);
  параметры подбираются оптимизатором по истории повторений пользователя.
  Источник: [fsrs4anki на GitHub](https://github.com/open-spaced-repetition/fsrs4anki).
- [предположение] Для ВКР Anki важен не как конкурент, а как образец:
  адаптивный планировщик V4 решает ту же задачу, что FSRS, и тоже требует
  полной истории ответов. Поэтому в модели данных `ReviewEvent` хранится
  без агрегации.

### Google Lens

Функция распознавания изображений Google, в том числе перевод текста через
камеру.

- [факт] ⚠ Конвейер в описании Google Research: захват изображения,
  обнаружение текста, анализ структуры, перевод, наложение перевода на
  исходное изображение с подбором размера шрифта. Источник:
  [блог Google Research](https://research.google/blog/giving-lens-new-reading-capabilities-in-google-go/).
- [сторонний] С 2021 года на Android доступен офлайн-перевод в Lens после
  загрузки языкового пакета. Источники:
  [9to5Google](https://9to5google.com/2021/01/25/google-lens-translate-offline/),
  [Android Central](https://www.androidcentral.com/you-can-now-use-google-lens-offline-translations).
- [сторонний] В Google Translate режим камеры перешёл на Lens. Источник:
  [Android Central](https://androidcentral.com/apps-software/google-lens-will-replace-google-translate-camera-mode).
- [предположение] Lens — пример гибридного размещения: есть офлайн-режим на
  устройстве и онлайн-режим. Какие модели выполняются на устройстве в каждом
  режиме, официальные источники в выдаче не раскрывают. Использовать в ВКР как
  иллюстрацию гибридной схемы, а не как точное описание реализации.

## 1.4. Выводы по обзору

1. [факт] Задача получения текста из игры решена в нескольких открытых
   проектах двумя способами: перехватом из процесса (LunaTranslator,
   Game2Text) и OCR с экрана (Translumo, Game2Text, Playto).
2. [факт] Связь с Anki есть почти у всех обучающих инструментов: это
   стандартный способ отдать повторение внешней системе.
3. [предположение] Ни один из рассмотренных инструментов по открытым
   источникам не передаёт в объяснение фразы **явный контекст произведения**:
   название, соседние реплики, сцену. Это ниша, которую занимает EasyLangApi.
   Утверждение основано на отсутствии упоминаний и должно звучать в ВКР
   осторожно: «в открытых описаниях не заявлено».
4. [предположение] Второе отличие — модель данных, где наблюдение (`Lookup`)
   отделено от элемента знания (`KnowledgeItem`), а история ответов
   (`ReviewEvent`) хранится полностью для адаптивного планировщика.
   В аналогах устройство хранения не описано, поэтому сравнивать по этому
   пункту можно только с Anki/FSRS.

- [ ] Выяснить, где работает языковая модель в Playto.
- [ ] Проверить, передаёт ли LunaTranslator соседние реплики в LLM-перевод
      (документация lunatranslator.org).
- [ ] Уточнить по истории Translumo, когда убрали Tesseract.
- [ ] Заменить цены на официальные или убрать их совсем: для ВКР они не важны.
- [ ] Оформить ссылки по ГОСТ Р 7.0.100-2018 с датой обращения.

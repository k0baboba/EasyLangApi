# Материалы для ВКР

Черновые материалы для выпускной квалификационной работы по теме
«Разработка интеллектуальных систем» на основе проекта EasyLangApi.

Статус: черновик, собран 2026-11-04; разделы 2–5 сверены с кодом ветки `prototype`
(версии V1–V7 и обучаемый планировщик из `srs/`). Что сделано и что проверено запуском —
в [`STATUS.md`](../STATUS.md), эксперимент с планировщиками — в [`srs/REPORT.md`](../srs/REPORT.md).

## Пометки в тексте

- **[факт]** — подтверждено источником, ссылка рядом, или следует из `SPEC.md`.
- **[код]** — так устроено в коде ветки `prototype`; путь к файлу рядом. Если код
  расходится со `SPEC.md` или с прежним текстом черновика, это сказано явно.
- **[сторонний]** — источник есть, но это сторонний обзор; перепроверить по первоисточнику.
- **[предположение]** / **[предложено]** — вывод или предложение автора черновика, источником не подтверждены.
- ⚠ — сведения взяты из фрагментов поисковой выдачи: страница при сборе
  не открывалась. Перед использованием открыть и сверить.

## Ограничения сбора

- Из среды, где готовился черновик, полностью открывались только страницы
  GitHub. Сайты Playto, Anki, Language Reactor, Migaku и Google Research
  были недоступны, поэтому сведения о них — из поисковой выдачи (⚠).
- Числа задержек и трафика в разделе 5 — оценки, а не измерения.
  Список нужных замеров приведён в 5.6.
- Первая версия черновика описывала целевое состояние по `SPEC.md`, когда кода основной
  логики ещё не было. Теперь код есть, и разделы 2–5 описывают его; прежние предположения,
  которые код подтвердил или опроверг, помечены **[код]**. Раздел 1 (аналоги) кода не касается.
- Синтаксис всех диаграмм mermaid проверен парсером mermaid 11.4.1 (и после обновления под код).

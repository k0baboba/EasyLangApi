## Пометки в тексте

- **[факт]** — подтверждено источником, ссылка рядом, или следует из `SPEC.md`.
- **[сторонний]** — источник есть, но это сторонний обзор; перепроверить по первоисточнику.
- **[предположение]** / **[предложено]** — вывод или предложение автора черновика, источником не подтверждены.
- ⚠ — сведения взяты из фрагментов поисковой выдачи: страница при сборе
  не открывалась. Перед использованием открыть и сверить.

## Ограничения сбора

- Из среды, где готовился черновик, полностью открывались только страницы
  GitHub. Сайты Playto, Anki, Language Reactor, Migaku и Google Research
  были недоступны, поэтому сведения о них — из поисковой выдачи (⚠).
- Числа задержек и трафика в разделе 5 — оценки, а не измерения.
  Список нужных замеров приведён в 5.6.
- Архитектура описывает целевое состояние по `SPEC.md`: кода основной
  логики в репозитории пока нет.
- Синтаксис всех диаграмм mermaid проверен парсером mermaid 11.4.1.

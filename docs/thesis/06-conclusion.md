# Заключение

## Что сделано

1. Проанализированы восемь аналогов по шести критериям. Ни в одном из
   открытых описаний не заявлена передача в объяснение контекста
   произведения (глава 1).
2. Сформулированы требования и спроектирована архитектура: монолит с тремя
   точками расширения «интерфейс + реализации». Наблюдение отделено от
   элемента знания, полная история ответов хранится без агрегации (глава 2).
3. Реализован сквозной поток: субтитры или снимок экрана → разбор фразы с
   контекстом → словарь → повторение, с пользователями и лимитами (глава 3).
4. Реализована обучаемая модель забывания (half-life regression): перенесена
   из симуляции на Python в C# с точным совпадением решений (глава 3).
5. Проведена оценка (глава 4):
   - 142 автотеста проходят;
   - на живой проверке словарь без контекста ошибся во всех трёх
     однословных фразах из сцены, а модель с контекстом передала смысл, но
     смешивала языки и отвечала 22–41 с на CPU;
   - в симуляции без лимита обучаемая модель при равной нагрузке даёт на
     17 % больше уверенно помнимых слов, чем лестница; при дневном лимите она
     проигрывала, пока очередь шла по дате, и выиграла для целей 0,8–0,9
     после перехода на очередь по вероятности забыть.

- Польза контекста для объяснения пока не доказана числами: проба на 5
  фразах статистически ничего не показывает, полный прогон — `[ЗАМЕР]`.
- Планировщик проверен на синтетическом ученике; проверка на данных людей —
  `[ЗАМЕР]`.
- Модель 7B на CPU слишком медленна для оверлея; на GPU — `[ЗАМЕР]`.
- Качество распознавания на реальных снимках игр не измерено — `[ЗАМЕР]`.
- Десктопный клиент проверен только частично ([`STATUS.md`](../../STATUS.md)).
- Известные гонки при параллельных запросах описаны в [`docs/guide.md`](../guide.md)
  (вопрос 17, задачи 4–5) и не исправлены в основной ветке.

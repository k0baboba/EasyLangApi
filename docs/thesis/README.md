# Черновик ВКР

> **Это черновик, собранный автоматически по файлам репозитория.** Автор
> перепишет его своими словами: текст нужен как каркас и как список фактов
> со ссылками, а не как готовая работа. Формулировки, структура глав и
> оформление по требованиям кафедры остаются за автором.

Тема: «Разработка интеллектуальных систем». Работа: интеллектуальная система
поддержки изучения английского языка по развлекательному контенту (EasyLangApi).

## Правила, по которым написан черновик

- **Числа только из файлов репозитория.** Рядом с каждым числом — ссылка на
  файл, из которого оно взято. Результаты прогонов на GitHub Actions лежат в
  ветке `results`, ссылки на них ведут на GitHub.
- **`[ЗАМЕР]`** — величина, которую ещё не измеряли. Число не придумано, его
  нужно получить и вставить.
- **`[не открыт]`** — источник, который при подготовке черновика не
  открывался: сведения о нём взяты из других файлов или из поисковой выдачи.
  Перед сдачей открыть и сверить. Подробнее об ограничениях сбора —
  [`docs/01-analogs.md`](../01-analogs.md).
- Подробные версии разделов лежат рядом в `docs/`: обзор аналогов, требования,
  архитектура, размещение OCR, руководство по коду. Черновик ссылается на них,
  а не повторяет целиком.

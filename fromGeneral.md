## Правила для всех

1. `main` не трогать: слияние в него решает владелец.
2. Задачи 4, 5 и 6 из docs/guide.md (гонки и повторы к словарю) не чинить: их делает владелец сам.
3. `prototype` общая ветка. Перед пушем в неё делай fetch, вливай origin/prototype и прогоняй тесты. Без force push.
4. Кто меняет поведение кода, тот в этом же коммите обновляет STATUS.md, а если guide уже влит, то и docs/guide.md.
5. В отчёты идут только настоящие результаты. Если гипотеза не подтвердилась, так и напиши: отрицательный результат тоже результат.
6. Репозиторий публичный: без ключей, токенов и сведений о владельце.
7. Итог каждой части пиши в свой toGeneral/sessionN.md.

## GitHub Actions как способ выйти в сеть

В облачной среде сеть закрыта, на раннерах она открыта. Значит, настоящие модели, словарь и данные можно запускать там. По документации GitHub для публичного репозитория:
- стандартные раннеры бесплатны;
- ubuntu-latest и windows-latest: 4 CPU, 16 ГБ памяти, 14 ГБ SSD, GPU нет;
- одна задача идёт до 6 часов;
- разрешено только то, что относится к разработке и тестированию этого проекта;
- GitHub Models закрыт 30.07.2026, не используй его.

Как делать:
- Тяжёлый workflow запускается только пушем в свою ветку `run/...`, не на каждый пуш и не по расписанию.
- `timeout-minutes` не больше 340. Сохранение результатов выполняется с `if: always()`, чтобы обрыв ничего не терял.
- Результаты идут в ветку `results`, каждая задача в свою папку, и дублируются в artifact. Модели и большие данные не коммить и в artifact не клади.
- `permissions: contents: write` только у этих workflow. При пуше в `results` делай rebase и повторяй попытку.
- Не дежурь у длинного прогона. Убедись, что пробный этап прошёл, а основной пошёл, запиши в toGeneral название workflow и переходи дальше. Готовые результаты заберёт координатор.

Лицензия CC BY-NC 4.0: данные не коммить, публикуй только свои агрегаты и укажи авторство. Обучи модель с признаками нашего планировщика, раздели данные по времени без заглядывания в будущее, сравни с простыми базовыми линиями по MAE, AUC и калибровке.
